Getting started

SpellDirector turns a loose idea or a reference clip into a spell effect your game can use.

‹ Viewer
1. Talk to the director 2. Connect your AI 3. What to ask 4. The viewer 5. Export for your engine

Mostly, you talk to an AI

SpellDirector is driven by an AI director. You describe a spell in plain words (“heavy boss lightning for a top-down game”) or hand it a GIF, and the director asks you a couple of simple choices, writes the spell as a template, checks it and saves it. This viewer is where you look at the result and export it.

  1. You ask for a spell, or share a clip.
  2. The director asks 2 or 3 plain-word choices.
  3. It saves a template and gives you a viewer link.
  4. You review it here and export sprite sheets.

You don't need to know any VFX terms. The director does.

2. Connect your AI

The director runs inside an AI app on this computer: Claude Desktop (easiest, free download from claude.ai/download), Claude Code, or Codex (in the ChatGPT desktop app). Three steps:

  1. Click Connect next to your AI app below.
  2. Restart that app. For Claude Desktop, right-click its icon by the clock and choose Quit, then open it again.
  3. Ask it List the SpellDirector spells. A list means you're connected.

Connect works when this page is opened from the SpellDirector app (double-click the .exe, then ? Help). Otherwise, follow the setup guide.

Connect adds a spelldirector entry to the app's settings and keeps everything else (the old file is saved as .bak). The first start can take up to a minute while the app unpacks. Your spells, exports and breakdowns are saved on this computer in a SpellDirector Library folder next to the app.

Updating to a new version

Download the new .exe into the same folder as the old one and double-click it once. It switches your connected AI apps to the new version by itself (the black window says so). Restart the AI app. Your spells stay where they are.

Let an AI walk you through it

The folder paths on this page are filled in for this computer, so the prompts work when you paste them. Nothing is built into the app: on someone else's computer this page shows their own folders.

Claude Code or Codex

They can run the setup for you.

Set up SpellDirector for me. Run this once in PowerShell: & "C:\Users\me\Documents\SpellDirector\SpellDirector-vX.Y.Z-windows.exe" --setup Show me what it printed and tell me which apps I need to restart. Don't edit any settings files by hand; that command does it safely and keeps a backup.

ChatGPT or Claude on the web

They can't touch your computer, so they guide you.

Use only these facts and don't add steps: (1) The app is already running: a black window and a browser page are open. (2) I need Claude Desktop, from claude.ai/download. (3) In the SpellDirector browser page, click "? Help", then "Connect" next to Claude Desktop. (4) Fully quit Claude Desktop: right-click its icon by the clock, choose Quit, then open it again. (5) In Claude Desktop, type "List the SpellDirector spells." It can take up to a minute the first time. If something goes wrong, ask me what I see on screen.

What about ChatGPT?

  • Codex (in the ChatGPT desktop app, the Codex command line and VS Code extension) works as the director: use its Connect button.
  • The ChatGPT website and ordinary ChatGPT chats can't run programs on your computer, so they can't be the director. They only connect to servers on the internet.

No connection? Any AI chat can still write a spell for you. Attach these files: director-playbook.md, vocabulary.md, template-format.md and template-schema.json, then ask:

Follow director-playbook.md and write a SpellDirector template (JSON) for: a slow, heavy boss lightning strike for a top-down game. Ask me your 2 or 3 questions first, then give me only the JSON.

Save the reply as a .json file and open it with Open JSON… in the viewer. To keep it in the spell list, put it in SpellDirector Library\templates\<element>\, for example templates\lightning\my-spell.json.

Set it up by hand, or from the source folder

Claude Desktop

Settings → Developer → Edit Config opens claude_desktop_config.json. Add this (merge it into "mcpServers" if that's already there):

{
  "mcpServers": {
    "spelldirector": {
      "command": "C:\\path\\to\\SpellDirector-vX.Y.Z-windows.exe",
      "args": ["--mcp"]
    }
  }
}

To keep your spells somewhere else, add "--library", "D:\\My Spells" to args.

Claude Code

claude mcp add --scope user spelldirector -- "C:\path\to\SpellDirector-vX.Y.Z-windows.exe" --mcp

Codex

At the end of %USERPROFILE%\.codex\config.toml:

[mcp_servers.spelldirector]
command = "C:\\path\\to\\SpellDirector-vX.Y.Z-windows.exe"
args = ["--mcp"]
startup_timeout_sec = 120

From the source folder (with Python)

  1. Get the source folder: git clone https://github.com/bgoldbeck/spell-director
  2. Install the packages once: python -m pip install -r requirements-dev.txt
  3. Run python tools/client_setup.py to connect the AI apps it finds, or open Claude Code in that folder: it finds the spelldirector server in .mcp.json and asks you to allow it.

By hand, the server is python -m director.mcp_server with the folder on PYTHONPATH:

{
  "mcpServers": {
    "spelldirector": {
      "command": "python",
      "args": ["-m", "director.mcp_server"],
      "env": { "PYTHONPATH": "C:\\path\\to\\spell-director" }
    }
  }
}

From the source folder, templates the director saves land in that folder's templates/, so open them with run.bat there.

Stuck? The full setup guide has a troubleshooting list.

3. What to ask

Just say what you want in your own words. Or start one of the director's three ready-made prompts (in Claude Code, type / and look for spelldirector):

Direct a spell

/mcp__spelldirector__direct_spell

Direct a spell: a quick chain shock that jumps between three enemies, side-scroller.

Direct from a GIF or video

/mcp__spelldirector__direct_from_gif

Direct a spell from this clip: C:\Clips\storm.gif. Keep the slow charge-up, but make it violet.

Grow the library

/mcp__spelldirector__grow_library

Grow the library: write 3 new lightning spells that feel different from the ones we have.

What the director asks you

At most two or three questions, once, each as a short choice with its pick first. Typical ones:

  • Camera: top-down, angled (isometric), side-on, or behind the character?
  • Charge-up: a long, heavy build-up or near-instant?
  • Shape, area or color: one clean bolt or a wild tree of forks, one target or the whole area, classic white-blue or a colored variant?

Not sure? Say you pick. The director decides the rest itself, explains why in the template's notes, and gives you a link that opens the new spell here.

Tip: Analyze GIF/MP4… in the viewer breaks a clip down on this computer and can copy a ready prompt for the director.

4. The viewer

Every spell plays as a looping motion study. Here's what's on screen, top to bottom:

Version badge
The small v… next to the title is the version you're running. Compare it with the Releases page to see if there's a newer one.
Type and Spell
Pick a kind of spell (for example Lightning, a spell line such as Paladin, or Auras: effects that hold round a character in a seamless loop), then a spell of that type. ‹ Prev and Next ›, or the [ and ] keys, step through them.
Views
Front, Side, Top and 3/4 show the same moment from the four standard game cameras. All four shows them side by side. Drag to orbit, scroll to zoom.
Playback
Replay, Pause, Speed (try 0.25× to study timing), Loop, and the timeline scrubber. The colored buttons under it jump to each beat, and the caption explains what that beat is for.
Seed and New cast
The same spell, cast a little differently each time. Keep a seed you like, since exports use it.
Sound
Off by default. Click Sound off or press M to hear the cue sounds. They are procedural placeholders: exports include them as WAV files plus a prompt and recipe per sound for making the real ones. It remembers your choice.
Style
Draw the spell Stylized (the default look), Realistic (ground that cracks open with depth, lava in the cracks, six-way lit smoke, filmic color), Toon (flat bands, ink outlines) or Pixel art. Press S to cycle. Template's uses the style the spell was made for. Exports use the same style and explain how to build it in Unity or Godot.
Volumetric
A layer marked volumetric in the layer list is meant to have a body: it should look thick from every side (front, side, top and 3/4), never a flat card or strip. The viewer draws it facing the camera; exports tell Unity or Godot how to build it with crossed or camera-facing layers, a bright core inside a softer shell and soft edges.
Six-way lit smoke
Smoke marked six-way lit in the layer list (and all dark smoke in the Realistic style) is lit by the lights around it: dark underneath, the color of a light beside it, glowing at its edges when a light is behind it. Exports include its two six-way lightmaps for Unity or Godot. To see it work, open Neon Campfire (Fire) and watch neon lights take turns from every side.
Bloom
On by default: bright light glows past its edges. Untick Bloom or press B to see the bare shapes.
Open JSON…
Load a template file from anywhere on your computer.
Analyze GIF/MP4…
Drop a reference clip to see its camera shots, phase timeline, palette, footprint and best view. Nothing leaves your computer.
Focus view
Hides everything but the stage, for screen recording. Esc brings it back.

5. Export for your engine

Export sprites… saves the current spell and seed as a .zip you can bring into Unity, Godot or any engine. Pick the views, the cell size and the frame rate, then Export .zip. You get:

  • One sprite sheet per layer (bolt, glow, sparks, smoke and so on), so you can tint, blend or time each layer on its own, plus all.png with the whole spell.
  • A JSON file with each layer's timing and the grid layout.
  • A guide that walks you through rebuilding the spell in the engine.
frame 1frame 2frame 3… Front Side Top 3/4

Columns are frames, rows are views. Read one row left to right to play the spell from that camera. Every cell is the same size and shares the same center point, and cells line up across all the layer sheets, so stacking the layers rebuilds the full spell. Very long spells wrap onto more rows so no sheet is wider than 4096 px.

Your AI can export too: ask the director to “export sprites for sky strike”, and it can look at the sheets cell by cell to check them.

GIFs to share

Export GIF… records the spell as you see it in the viewer, as looping animated GIFs. Tick the views you want (Front, Side, Top, 3/4, All four in one GIF) or All, pick the size, frame rate and speed, then Export GIF. One view downloads as a .gif, several as a .zip. Auras record their seamless loop, so they hold forever. Layers you've unticked are left out.
