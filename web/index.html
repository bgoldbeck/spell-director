About this effect

Layers

    Export sprite sheets

    One sheet per layer, plus one for the whole spell. Columns are frames and rows are the views, so each column shows one moment from every view. You get a .zip with the sheets, a JSON file and a guide for rebuilding the spell in Unity or Godot. Uses the current seed.

    Views

    Export GIF

    Records the spell as the viewer shows it: the set and stand-ins, bloom, the art style, camera shake and screen flashes. One looping GIF per view you pick; several views come as a .zip. Uses the current seed, and leaves out layers you've unticked.
