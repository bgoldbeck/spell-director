# Sound cue library

Templates don't hold audio. A `sound_cue` layer names a **cue** (`crack`, `buzz`, `fire`, ...) and the beats it plays in; the viewer plays that cue in sync. [`cues.json`](cues.json) is the cue library and the single source of truth: the validator, the director (`get_sound_cues`) and the viewer all read it.

## What plays today

Every cue has a **sound bank** in [`bank/`](bank): real sound files in three sizes (`small`, `medium`, `large`) with three takes each, named `<cue>-<s|m|l>-<take>.ogg`. They are generated by [`tools/soundbank.py`](../../tools/soundbank.py) (layered synthesis, CC0) and listed on each cue in `cues.json` as `{"file", "size", "duration_ms"}`. A layer's `size` param picks the size; each play picks a take from its seed. Cues with no samples fall back to a procedural placeholder in [`web/js/audio.js`](../js/audio.js).

To change a bank sound, edit its recipe in `tools/soundbank.py` and run `python tools/soundbank.py <cue>` (needs numpy and ffmpeg). It rewrites that cue's files and its `samples` list, keeping any recordings.

## Adding a recording

No code changes are needed.

1. Get a short sound with a clear license (see below).
2. Run `python tools/soundbank.py import <cue> path/to/file.wav --size medium --source <URL> --author <name> --license CC0`. It trims the silence before the transient, normalizes to -1 dBFS, writes `samples/<cue>-<n>.ogg`, lists it on the cue and adds the credits row. (By hand: put the file in `samples/`, add `{"file": "samples/<cue>-1.ogg", "size": "medium", "duration_ms": 420}` to the cue's `samples`, and add a row to [`CREDITS.md`](CREDITS.md).)
3. A recording plays alongside the bank takes of its size. To use only recordings, delete the cue's `bank/` entries from `samples`.

One-shot cues play the whole sample. Sustained cues loop the sample if it's shorter than the beat and fade out at the end, so loopable recordings work best for `hum`, `buzz`, `fire`, `wind` and the like. If a sample fails to load, the viewer falls back to the placeholder and logs a warning.

### Licensing

Only add sounds that can ship in this repo:

- **CC0 / public domain** (preferred): no attribution needed, but still list it in `CREDITS.md`. Good sources: Freesound filtered to CC0, Kenney's audio packs, OpenGameArt filtered to CC0, Sonniss GDC bundles (royalty-free; check the bundle license).
- **CC-BY**: allowed only with the attribution in `CREDITS.md`.
- Not allowed: CC-BY-NC, CC-BY-SA, "free for personal use", ripped game audio, or anything without a clear license.

### What each cue should sound like

Each cue carries a sound brief in the words of [docs/sound-design.md](../../docs/sound-design.md): `character` (texture, pitch, envelope, the layers it's built from, tail, space), a `synth` recipe (how to make it procedurally) and `search` terms for sound libraries. `flavors` adds element words (water, blood, dark, ...) to the prompts. Exports turn all of this into a per-spell cue sheet (`<id>.sounds.json`) and render the placeholders to WAV files.

### Text-to-SFX

Each cue has an `sfx_prompt`, a ready prompt for a text-to-SFX service. Generate a few takes, keep the best, and add them as samples like any other file (record the service and its license terms in `CREDITS.md`).

## Adding a new cue

Add an entry to `cues.json` (`label`, `category`, `kind` = `one_shot` or `sustained`, `duration_ms`, `describes`, `words`, `phases`, `character`, `sfx_prompt`, `synth`, `search`, `samples`), add a placeholder recipe with the same name to `RECIPES` in `web/js/audio.js` and a bank recipe to `tools/soundbank.py` (tests check every cue has both), run `python tools/soundbank.py <cue>`, and add it to the cue table in `docs/vocabulary.md` §10 and `docs/template-format.md`.
